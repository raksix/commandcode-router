İstemci Bağlama

Claude Code'u bu proxy'ye bağlamak için:

ANTHROPIC_BASE_URL=http://localhost:3025
ANTHROPIC_AUTH_TOKEN=<masterKey>
# Modeli netleştirmek istersen:
ANTHROPIC_MODEL=deepseek/deepseek-v4-flash

ANTHROPIC_BASE_URL sonuna /v1 EKLEME — Claude Code kendisi /v1/messages ekler.

cURL ile Test

# Model listesi
curl http://localhost:3025/v1/models \
  -H "Authorization: Bearer <masterKey>"

# Mesaj gönder (stream)
curl -X POST http://localhost:3025/v1/messages \
  -H "Authorization: Bearer <masterKey>" \
  -H "Content-Type: application/json" \
  -H "anthropic-version: 2023-06-01" \
  -d '{"model":"claude-sonnet-5","max_tokens":100,"stream":true,"messages":[{"role":"user","content":"selam"}]}'

Notlar

  • Havuzdaki hesaplar round-robin ile döner; bir hesap hata verirse sıradakine geçilir (max 2 retry).
  • Ardışık 5 hata sonrası hesap otomatik banlanır (panelden kaldırılır).
  • /v1/* uç noktaları master key ister; panel admin şifresi + HttpOnly cookie kullanır.
  • OSS modeller (deepseek/gpt gibi) otomatik olarak OpenAI formatına çevrilir.
